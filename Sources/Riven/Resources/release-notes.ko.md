## 이번에 고친 것들

- **에이전트에게 일을 넘길 때** 리드 대화에 **"진행 중…" → "완료"** 가 표시됩니다. 비동기로 넘긴 일이 돌고 있는지 끝났는지 이제 바로 보입니다.
- **문서 저장 위치.** `riven_doc_write` 로 만든 문서가 이제 **그 워크스페이스의 `.claude/docs`** 에 저장되고 문서 탭에 뜹니다 (예전엔 엉뚱한 위치로 가서 안 보였습니다).
- **대기 중인 멤버가 "작업 중" 으로 잘못 보이던 문제** — 실제로 돌고 있는 세션만 작업 중으로 표시합니다.
- **워크스페이스 카드 클릭** — 세 번째 카드를 눌렀는데 첫 번째로 튀던 문제를 고쳤습니다 (같은 폴더가 카드 두 개로 갈라지던 원인 제거).
- **스크롤 막대를 항상 표시하는 Mac** 에서 설정 창 등에 **가로 스크롤이 생기던 문제** 를 없앴습니다.
- **업데이트 후 릴리스 노트** 가 로그인한 다른 기기에서 안 뜨던 문제를 고쳤습니다.
