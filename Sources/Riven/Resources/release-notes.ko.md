## Codex 를 네이티브 챗으로

⌘O 에서 Codex 를 고르면 터미널이 아니라 **네이티브 챗**이 열립니다. Claude 챗과 같은 자리에서 스트리밍, 승인 카드, 변경사항 연동, 토큰 표시가 그대로 동작합니다.

- **승인 모드**가 Codex 에도 적용됩니다 (계획 / 승인 요청 / 자동)
- 대화가 **재시작 후에도 이어집니다**
- 탭·사이드바 아이콘으로 어느 CLI 인지 한눈에 구분됩니다

## 사용량을 CLI 별로

헤더의 사용량이 Claude 와 Codex 를 **따로** 보여 줍니다. 예전에는 Claude 것만 세고 있어서, Codex 로 아무리 돌려도 눈금이 움직이지 않았습니다.

- **남은 % / 쓴 %** 를 고를 수 있습니다 (설정 → 일반 → 사용량, 또는 막대를 클릭)
- 사이드바에 고정했을 때도 CLI 마다 나뉘어 보입니다

## 고친 것

- **같은 폴더가 워크스페이스 카드 두 개로 갈라지던 문제.** 오래 쓴 세션에서 생길 수 있었고, 어느 카드를 누르냐에 따라 다른 패널이 떴습니다. 이번 실행에서 자동으로 하나로 합쳐집니다 (열려 있던 탭은 그대로 유지됩니다)
- 재시작할 때 보던 워크스페이스가 아닌 곳이 열리던 문제
- Codex 대화에서 `/cost`·`/status`·세션 목록이 **Claude 계정**의 정보를 보여 주던 문제
- 사용량 안내 문구가 두 줄로 겹쳐 보이던 문제

## 설정

- 에디터: **탭 크기 · 줄바꿈 · 미니맵 · 폰트 합자**
- 브라우저 **기본 검색 엔진**
- 새 대화의 **기본 모델 · 기본 승인 모드**
- **자동 업데이트 끄기**, 설정 파일 위치, 설정 초기화, 단축키 기본값 복원
- 설치된 에이전트 CLI 목록 (경로·버전)
