## 직렬 파이프라인 그룹

여러 단계를 순서대로 거치는 에이전트 팀을 만들 수 있습니다. **에이전트 그룹 패널 → "새 그룹" → [파이프라인]** 에서 기획 → 디자인 → 개발 → QA → 배포처럼 단계를 세우고, **각 단계의 역할을 프롬프트로 고정**한 뒤 작업을 넣으면:

- 단계가 순서대로 **자동 실행**되고, 앞 단계의 산출물이 다음 단계로 넘어갑니다.
- 마지막 단계에서 전체를 **총정리**합니다.
- 중간 단계를 멈추면 그 뒤로 넘어가지 않고 거기서 멈춥니다.

에이전트에게 "이 작업 파이프라인으로 진행해" 라고 시켜도 됩니다.

## 그 밖에 고친 것

- 백그라운드 서브에이전트가 끝나 대화가 이어질 때, 패널이 다시 **진행 중 → 완료**로 제대로 표시됩니다 (예전엔 "완료"에 멈춰 있어 진짜 끝났는지 알기 어려웠습니다).
