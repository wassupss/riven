## 검색이 VSCode 처럼

파일 검색이 **`.gitignore` 를 존중**합니다. `.build`·`node_modules` 같은 빌드 산출물이 더는 결과에 섞이지 않아, 원하는 코드가 바로 보입니다. 검색창 오른쪽에 **대소문자(Aa) · 단어 단위(W) · 정규식(.*)** 토글도 생겼습니다.

## MCP 서버를 앱 안에서 바로

채팅에서 `/mcp` 를 치면 연결된 서버와 상태(사용 중 / 인증 필요)가 보입니다. **"MCP 서버 추가"** 로 이름과 명령(또는 URL)만 넣으면 riven 이 내부에서 추가하고 자동으로 재연결합니다. 터미널을 따로 열 필요가 없습니다.

## 워크스페이스마다 변경 개수

왼쪽 레일의 워크스페이스 카드에, 브랜치 옆에 **로컬 변경 파일 수**가 표시됩니다 (VSCode 처럼).
