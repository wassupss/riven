## MCP 서버를 앱 안에서 관리

채팅에서 `/mcp` 를 치면 이제 워크스페이스에 설정된 MCP 서버 목록과 상태(● 사용 중 / ○ 인증 필요)가 제대로 뜹니다. 바로 이어서:

- **추가**: `claude mcp add` 뒤에 올 인자를 그대로 붙여넣으면 riven 이 실행합니다. `--transport http ... --header "Authorization: Bearer ..."` 같은 형태도 그대로 됩니다.
- **인증**: 인증이 필요한 서버를 고르면 브라우저가 열려 로그인합니다. 터미널을 열 필요가 없습니다.
- **제거**: 뺄 서버를 골라 지웁니다.

전부 앱 안에서 처리하고, 끝나면 자동으로 다시 연결합니다.
