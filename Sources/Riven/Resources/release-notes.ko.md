## 고정 프롬프트: 모든 에이전트에 붙는 나만의 지침

설정 → AI 에 **고정 프롬프트** 가 생겼습니다. CLAUDE.md 처럼, 여기 적은 지침이 riven 의 모든 에이전트(챗·터미널)에 자동으로 붙습니다. **템플릿 4종**(따뜻한 톤 / 간결하게 / 꼼꼼한 리뷰 / 한국어 우선)을 골라 바로 넣을 수도 있어요.

## 세션이 업데이트에도 안전하게

워크스페이스별 세션(열린 탭·패널·그룹)에 **스키마 버전과 자동 마이그레이션**을 넣어, 앞으로 구조가 바뀌어도 옛 세션이 안전하게 열립니다. 혹시 꼬이더라도 설정 → 정보 → 유지보수의 **"백업으로 복원"** 으로 업데이트 이전 상태로 되돌릴 수 있습니다.

## 그 밖에 고친 것

- **패널을 옮길 때** 가끔 패널 안이 텅 비어 보이던 문제를 고쳤습니다.
- **설정에서 다른 메뉴를 눌러도** 바꾼 것 없이 "저장됨" 이 뜨던 문제를 고쳤습니다.

## 그리고

업데이트한 뒤 처음 켜면 이 화면이 뜹니다. 설정 → 정보에서 언제든 다시 볼 수 있습니다.
