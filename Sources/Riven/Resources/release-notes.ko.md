## 에이전트 채팅을 새로 다듬었습니다

답변 스트리밍이 한 글자씩 부드럽게 나타나고, 표·인용구·코드조각이 마크다운 원문 그대로 잠깐 보이던 문제도 없앴습니다. 완료 줄에는 체크와 함께 걸린 시간·토큰이 정갈하게 붙고, 권한 모드 전환이나 모델 변경 같은 알림은 작은 칩으로 바뀌었습니다.

## 실행한 명령을 하나로 묶었습니다

Read·Bash·Edit 같은 도구 호출이 "명령 N개" 아코디언으로 묶여 대화 흐름을 어지럽히지 않습니다. 펼치면 각 명령이 보이고, 코드가 있는 명령은 눌러서 코드블록을 볼 수 있습니다. Edit 로 바뀐 양은 옆에 +/- 로 표시됩니다. 껐다 켜서 세션이 돌아와도 이 명령 기록이 그대로 살아납니다.

## 안정성·성능

파일 변경을 기록할 때 드물게 앱이 튕기던 문제(broken pipe)를 고쳤고, 터미널은 앱이 뒤에 있거나 탭이 가려지면 그리기를 멈춰 CPU를 아낍니다.
