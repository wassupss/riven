## 실행한 명령을 접이식 패널로

Read·Bash·Edit 같은 도구 호출이 테두리 있는 "명령 N개" 패널로 묶여 대화가 깔끔해집니다. 실행 중엔 테두리가 은은히 움직이고 현재 명령이 제목에 뜨며, 끝나면 초록 테두리로 바뀝니다. 옆에는 실행·변경 개수와 Edit 변경량(+/-)이 보이고, 펼치면 각 명령을, 명령을 누르면 코드를 볼 수 있습니다. Edit 코드는 에디터처럼 초록/빨강 배경에 문법 색으로 표시됩니다.

## 서브에이전트를 한 곳에서

여러 서브에이전트가 저마다 컬럼을 차지하는 대신, 한 "서브에이전트" 패널에 목록으로 쌓입니다. 실행 중인 항목은 펼쳐서 진행을 보고, 끝나면 접힙니다.

## 진행 중에 끼어들기

에이전트가 작업하는 도중에 메시지를 보내면, 하던 걸 멈추고 이전 맥락까지 합쳐 바로 다시 답합니다. 끝날 때까지 기다리지 않아도 됩니다.

## 다음 작업 제안 (선택)

턴이 끝나면 입력창에 다음에 보낼 만한 지시를 흐리게 제안합니다. Tab 을 누르면 채워지고(바로 실행되진 않습니다), 그냥 타이핑하면 사라집니다. 설정 → 에이전트에서 켜세요.

## 그리고

답변 스트리밍이 더 매끄럽게 흐르고, 표 여백·유저 메시지 정렬·에이전트 그룹 패널 스크롤도 다듬었습니다. 업데이트 후 처음 켜면 이 화면이 뜨고, 설정 → 정보에서 다시 볼 수 있습니다.
