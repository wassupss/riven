## Commands fold into a panel

Tool calls like Read, Bash, and Edit are grouped into a bordered "N commands" panel so the conversation stays clean. While running, the border animates and the current command shows in the title; when done it turns green. Alongside it you see how many ran and changed (with +/- edit counts). Expand to see each command, and click one to view its code. Edit code now reads like an editor: green/red backgrounds with syntax colors.

## Sub-agents in one place

Instead of each sub-agent taking its own column, they stack as a list in a single "Sub-agents" panel. Running ones are expanded so you can watch them; finished ones collapse.

## Interrupt mid-turn

Send a message while the agent is working and it stops, folds in the earlier context, and answers right away. No need to wait for it to finish.

## Next-step suggestions (optional)

After a turn, the composer suggests a likely next instruction in dim text. Press Tab to fill it in (it does not run on its own); just start typing to dismiss it. Turn it on in Settings → Agents.
