riven is a native macOS IDE built around agent orchestration. Every agent gets its own panel, a nickname and a reporting line - and they hand work to each other. Editor, GPU terminals, web preview and Git dock wherever you want them. riven은 에이전트 오케스트레이션을 중심으로 만든 네이티브 macOS IDE입니다. 에이전트마다 자기 패널·닉네임·보고 라인을 갖고 서로 일을 넘깁니다. 에디터·GPU 터미널·웹 프리뷰·Git은 원하는 자리에 도킹됩니다.

Agent orchestration에이전트 오케스트레이션

One agent is a chat. Several are a team.에이전트 하나는 채팅, 여럿은 팀.

riven treats agents as first-class panels: they run side by side, know about each other, and hand work back and forth - while you watch every edit and approve every tool call.riven에서 에이전트는 일급 패널입니다. 나란히 돌아가고, 서로를 알고, 일을 주고받습니다. 그동안 모든 편집과 도구 호출은 당신 눈앞에서 승인됩니다.

Native AI chat panel네이티브 AI 채팅 패널 NEW

Chat with Claude Code inside the IDE - signed in with your existing subscription, no extra API key. Streaming answers, tool lines with inline diffs, image paste, interrupt mid-turn, queued messages, and plan-mode results as a clickable badge.IDE 안에서 Claude Code와 대화합니다. 쓰던 구독 로그인 그대로, 별도 API 키가 필요 없습니다. 스트리밍 답변, 편집 diff가 붙는 도구 라인, 이미지 붙여넣기, 진행 중 중단, 메시지 대기열, 계획 모드 결과 배지까지.

Agent groups & org chart에이전트 그룹 & 조직도 NEW

Give each agent a nickname, a persona, a model and someone to report to. riven lays the panes out by level and draws the reporting tree - click a node to jump to that agent, even one you closed.에이전트마다 닉네임·페르소나·모델·보고 대상을 정하면, riven이 계층대로 패널을 배치하고 보고 라인을 조직도로 그립니다. 노드를 클릭해 이동하고, 닫아둔 멤버도 클릭하면 세션째 되살아납니다.

Agents that drive the IDEIDE를 직접 쓰는 에이전트 NEW

A built-in MCP server hands agents riven's own tools: ask you a multiple-choice question, open a file at a line, preview a page, screenshot it, fire an API request, list or switch workspaces, open and close panels. Agents you launch in a terminal get the same tools.내장 MCP 서버가 riven의 도구를 에이전트에게 넘깁니다. 사용자에게 선택지 묻기, 특정 줄로 파일 열기, 페이지 미리보기·스크린샷, API 요청 실행, 워크스페이스 목록·전환, 패널 열고 닫기. 터미널에서 직접 띄운 CLI에도 같은 도구가 붙습니다.

Parallel delegation병렬 위임 NEW

An agent can hand unrelated tasks to several teammates in one call - they all start at once and the answers come back together. Sub-agents open as their own dock panels, so you see the work as it happens.에이전트가 서로 무관한 일을 여러 동료에게 한 번에 넘깁니다. 전원이 동시에 시작하고 응답은 모아서 돌아옵니다. 서브에이전트는 각자 도크 패널로 열려 진행 상황이 그대로 보입니다.

Agent-aware terminals에이전트를 아는 터미널

Claude Code, Codex, Gemini and Cursor Agent are detected wherever they're installed and open as panels. Lifecycle hooks report the real state - working, waiting for approval, done - so a pane never guesses from screen output, and each pane resumes its exact conversation on restart.Claude Code·Codex·Gemini·Cursor Agent를 설치 위치와 무관하게 찾아 패널로 엽니다. 라이프사이클 훅이 실제 상태(작업 중·승인 대기·완료)를 알려주므로 화면을 긁어 추측하지 않고, 각 패널은 재시작해도 그 대화를 그대로 이어갑니다.

Review every agent edit에이전트 편집 리뷰

A Changes timeline lists every file an agent touched this session with +/− line counts. Click a row to open it with a multi-hunk inline diff, then accept or revert - per file, per hunk, or all at once.Changes 타임라인이 이번 세션에 에이전트가 건드린 모든 파일을 +/− 줄 수와 함께 보여줍니다. 행을 클릭하면 멀티 헝크 인라인 diff로 열리고, 파일 단위·헝크 단위·일괄로 수락하거나 되돌립니다.

The workbench워크벤치

A real IDE under the agents.에이전트 아래엔, 진짜 IDE.

Native Swift and AppKit, GPU terminals from libghostty, the Monaco core from VS Code - no Electron shell in sight.네이티브 Swift·AppKit, libghostty의 GPU 터미널, VS Code의 Monaco 코어. Electron 껍데기는 없습니다.

Freely dockable panels자유 도킹 패널

Explorer, editor, terminals, chats and preview are all draggable panels - split them any way you like or pop one out into its own window. The whole layout is saved per workspace and restored on launch.탐색기·에디터·터미널·채팅·프리뷰가 모두 드래그 가능한 패널입니다. 원하는 대로 분할하고 별도 창으로 팝아웃하세요. 레이아웃 전체가 워크스페이스별로 저장되고 실행 시 복원됩니다.

GPU terminalsGPU 터미널

Real PTYs rendered by libghostty - the engine behind Ghostty. Full Korean IME, drag a file in to paste its path, and terminals survive workspace switches instead of being torn down.libghostty가 그리는 진짜 PTY - Ghostty의 그 엔진입니다. 한글 IME 완전 지원, 파일을 끌어다 놓으면 경로가 입력되고, 워크스페이스를 옮겨도 터미널은 죽지 않습니다.

Monaco editor + LSPMonaco 에디터 + LSP

The Monaco core from VS Code with VS Code-style split groups and Shiki syntax highlighting (tsx/jsx first-class), all bundled offline. TypeScript/JS get completion, hover, go-to-definition, references and diagnostics with zero setup.VS Code의 Monaco 코어에 VS Code식 분할 그룹, tsx/jsx까지 제대로 칠하는 Shiki 하이라이팅 - 전부 오프라인 번들입니다. TypeScript/JS는 무설정으로 자동완성·호버·정의 이동·참조·진단이 켜집니다.

Git with a commit graphGit + 커밋 그래프

Stage, commit, push and pull, browse diffs and read inline blame - plus a Fork-style graph with colored lanes, refs and a commit detail pane, right inside the source-control panel.스테이지·커밋·push/pull·diff·인라인 blame에 더해, 색 레인과 ref, 커밋 상세를 보여주는 Fork 스타일 그래프가 소스 컨트롤 패널 안에 있습니다.

API client & web previewAPI 클라이언트 & 웹 프리뷰

Save and fire HTTP requests with headers, params and auth in a panel next to your code, and keep a live preview of your dev server beside it. Agents can drive both.헤더·파라미터·인증까지 갖춘 HTTP 요청을 코드 옆 패널에서 저장하고 실행하세요. 개발 서버 라이브 프리뷰도 나란히 둘 수 있고, 둘 다 에이전트가 직접 조작할 수 있습니다.

Per-workspace notes워크스페이스 노트 NEW

A private notepad per project - a list of notes, autosaved. They live in riven's own storage, never in your working tree, so they never show up in git status or get swept into an agent's commit.프로젝트마다 붙는 개인 노트장. 여러 장을 목록으로 두고 자동 저장됩니다. 작업 트리가 아닌 riven 저장소에 있어서 git status에 뜨거나 에이전트 커밋에 딸려 들어가지 않습니다.
